# 🌤️ React Weather App

A responsive weather application built with **React** and **OpenWeatherMap API**. This app allows users to search for real-time weather information of any city in the world, displaying data like temperature, humidity, wind speed, and weather condition with clean and modern UI.

---

## 🚀 Features

- 🔍 City-based weather search
- 🌡️ Displays temperature, humidity, and wind speed
- 📷 Dynamic weather icons
- 📱 Responsive design for mobile and desktop
- 🎨 Clean UI with custom styling using CSS

---

## 🛠️ Tech Stack

- **React.js**
- **CSS**
- **OpenWeatherMap API**

The **React Weather App** is a simple and user-friendly tool for checking weather updates around the world. With a clean UI, responsive layout, and real-time API integration, it offers a great experience for users who want quick weather insights by just entering a city name.
